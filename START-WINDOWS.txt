1) Open this folder in VS Code.
2) Open Terminal.
3) Run: npm install
4) Run: npm run setup
5) Enter your REAL PostgreSQL password when asked.
6) Run: npm start
7) Open: http://localhost:3000

You do NOT need to type psql.
You do NOT need to manually create tables.
You do NOT need to manually create the database if the PostgreSQL user can create databases.
